description=Forest change detection: the binary change mask is produced by a neural model (3D-CNN + CfC, F1 0.943), the change type (logging / windfall / fire) is classified by a DOFA+CfC fusion network on 320 m cells.
version=0.11.0
author=Forest Hackathon Team
email=team@example.com
about=Detects forest cover changes between two dates (or a whole time series): the change mask is computed by a compact neural model - a 3D convolutional network over the multi-date volume fused with a CfC recurrent branch (binary F1 0.943 on held-out quarters, works with 2-36 dates) - and a siamese DOFA + CfC fusion network classifies the type of the changed 32 px (320 m) chips (logging/windfall/fire, macro-F1 0.938 among changed chips). Urban/water/bare pixels are excluded via Sentinel-2 SCL and an NDVI vegetation check. Outputs: class raster, merged change polygons and a cells layer (one polygon per changed cell with coordinates, type and confidence). Runs on CPU (onnxruntime); on AMD Windows an optional ROCm (torch) provider accelerates the type step ~6x.
