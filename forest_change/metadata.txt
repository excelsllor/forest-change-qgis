version=0.16.0
author=Forest Hackathon Team
email=team@example.com
about=Detects forest cover changes between two dates (or a whole time series): the change mask is computed by a neural model - a compact CNN over the multi-date volume fused with a bidirectional CfC recurrent branch (length-aware pooling, dynamic T 2-8 dates), temporal feature summaries and a 3x3 neighbourhood context (organizers F1 0.931, P 0.938 / recall 0.924) - and a TypeNet (distilled DOFA-style 12x768 encoder + CfC with mean/last-first temporal summaries, val macro-F1 0.870 on changed chips) classifies the type of the changed 32 px (320 m) chips (logging/windfall/fire). Urban/water/bare pixels are excluded via Sentinel-2 SCL and an NDVI vegetation check. Outputs: class raster, merged change polygons and a cells layer (one polygon per changed cell with coordinates, type and confidence). Runs on CPU (onnxruntime).
