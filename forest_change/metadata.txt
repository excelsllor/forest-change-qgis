description=Forest change detection: the binary change mask is produced by a neural model (CNN + bidirectional CfC, val F1 0.917), the change type (logging / windfall / fire) is classified by a distilled DOFA-style CNN encoder + CfC network on 320 m cells.
version=0.12.1
author=Forest Hackathon Team
email=team@example.com
about=Detects forest cover changes between two dates (or a whole time series): the change mask is computed by a neural model - a compact CNN over the multi-date volume fused with a bidirectional CfC recurrent branch (val F1 0.917, works with 2-8 dates) - and a TypeNet (distilled DOFA-style 12x768 encoder + CfC, val macro-F1 0.837 on changed chips) classifies the type of the changed 32 px (320 m) chips (logging/windfall/fire). Urban/water/bare pixels are excluded via Sentinel-2 SCL and an NDVI vegetation check. Outputs: class raster, merged change polygons and a cells layer (one polygon per changed cell with coordinates, type and confidence). Runs on CPU (onnxruntime).
