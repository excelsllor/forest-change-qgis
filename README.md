# Forest Change Detection — QGIS plugin (DOFA + CfC)

Выявление и классификация изменений лесного покрова по разновременным снимкам
Sentinel-2. **Наличие изменения определяет алгоритм** (порог по разнице NDVI/NBR),
а нейросеть классифицирует **тип** изменения среди изменённых чипов:
**siamese DOFA (ViT-B/16) + CfC (4 даты) + logit-stack fusion**. Инференс — на
**CPU** через `onnxruntime` (GPU-провайдеры DirectML/CUDA/ROCm подхватываются
автоматически). Геообработка — GDAL/OGR.

## Как работает

1. **Алгоритм**: попиксельная маска изменения `|ΔNDVI| > 0.15` или `|ΔNBR| > 0.15`
   между датами периода (порог настраивается в `core.py`: `CHANGE_THR`).
   Чип 32 px (320 м) считается изменённым, если изменённых пикселей ≥ 10 %
   (`CHANGE_FRAC`).
2. **Модель** (fusion, CPU): для изменённых чипов
   - spatial-ветка: DOFA-B, 6 каналов B02/B03/B04/B08/B11/B12, чип 32 px → 128 px;
   - temporal-ветка: CfC по 4 датам (9 признаков: 6 каналов + NDVI/NBR/NDMI);
   - logit-stack комбайнер → 4 класса (no_change / logging / windfall / fire).
3. Неизменённые чипы помечаются классом 0 без прогона сети; nodata и облака (SCL)
   → 255.

## Возможности

- Режимы: **period** (мозаики `<дата>_<band>.tif` + `<дата>_SCL.tif`) и
  **files** (два multi-band GeoTIFF с 6 выбранными каналами).
- Выходные данные: `classes.tif` (0 no_change, 1 logging, 2 windfall, 3 fire,
  255 nodata), `changes.gpkg` (полигоны с `type`, `area_ha`), `summary.json`.

## Установка

Требуется QGIS 3.16+ (проверено на 3.44 LTR, Python 3.12).

**Вариант A — из ZIP:** QGIS → *Модули → Управление модулями → Установить из ZIP*.

**Вариант B — вручную:** скопировать папку `forest_change` в
`%APPDATA%\QGIS\QGIS3\profiles\default\python\plugins\` и включить модуль.

Зависимость (CPU-инференс):

```powershell
<OSGeo4W>\apps\Python312\python.exe -m pip install onnxruntime
```

## Модель

Модель **не входит в репозиторий** (426 МБ, лимит GitHub — 100 МБ на файл).
Скачайте `forest_change_fusion128.onnx` из репозитория с моделями
[`forest-change-model` → Releases](https://github.com/excelsllor/forest-change-model/releases)
и положите в `forest_change/model/` (рядом — `forest_change_fusion128.json`).

## Точность (Вожегодское лесничество, held-out кварталы)

**Тип изменения среди изменённых чипов** (задача модели; change задаёт алгоритм):

| модель | logging | windfall | fire | macro-F1 (3 типа) |
|---|---|---|---|---|
| spatial DOFA | 0.932 | 0.939 | 0.770 | 0.880 |
| temporal CfC (4 даты) | 0.909 | 0.934 | 0.101 | 0.648 |
| **FUSION (DOFA+CfC)** | **0.942** | **0.966** | **0.907** | **0.938** |

**Конечная карта** (40 held-out кварталов, период 2025-07→2026-06, 1.86 млн пикселей)
с алгоритмическим гейтом: acc 0.964, но тип зависит от качества детектора
изменения (текущий простой порог NDVI/NBR пропускает слабые изменения:
logging F1 0.195). Детектор изменения — отдельная задача (можно заменить на
проектный спектральный скрининг или обученный детектор).

## Ограничения

- Простой порог NDVI/NBR — черновой детектор изменения; для продакшена нужна
  калибровка (или отдельная модель/скрининг).
- Ветровал и пожар на карте определяются детектором изменения, тип — моделью;
  редкие классы чувствительны к порогам.
